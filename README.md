## 📌 About The Project

This portfolio was created to build a professional online presence and showcase my journey in frontend development.

The website focuses on a clean, modern, and responsive user interface while keeping the codebase organized through reusable React components.

- Responsive design for desktop, tablet, and mobile
- Dark and light mode
- Smooth navigation between sections
- Modern and minimal UI
- Project showcase with images
- Skills and technologies section
- Contact section
- Mobile navigation menu
- Reusable React components
- Responsive layouts and animations
